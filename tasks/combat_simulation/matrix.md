@after simulate.md

A CLI to combine multiple runs of combat, character(s) vs monster(s) to report
on the expected deadliness of the combat, and produce a report.

- [ ] simulate 1,000 combats
        - returns the 10th/50th/90th percentile results
        - includes one example combat log

Run a full matrix of different numbers of characters against different numbers
of the monsters.

- [ ] simulate 1-n characters vs 1-n monsters
        - returns the matrix of results of each combination being run 1,000 times
        - pick one example combat log
