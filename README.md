# 5th Edition Monsters

An alternative collection of Creative Commons licensed 5th edition monsters
for you to use in your games.

Using the [D&D 5.5 SRD][52] as the baseline statblock to use, and then looking
to other freely available content including [D&D 5e SRD][51], [D&D 3.5e
SRD][35], [Tales of the Valiant's BFRD][bf], and [Level Up 5e SRD][a5e] for
inspiration, to tweak the statblock to encompass other good ideas.

Then, using all we know about these monsters from previous editions, fanart,
lore, and such (using them for inspiration, not verbatim plagarism) augment it
with:

- a fresh description
- original artwork
- original lore
- tactics and behaviours

And then top it off with the results of running a lot of simulated combats to
better understand the danger represented. All in order to help the DM on how
best to use the monster at their table.

As well as being collected here, this content will be presented on
[your5e.com][y5e], and downloadable in PDF and as an Obsidian vault.
